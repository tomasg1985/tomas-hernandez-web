## 🚀 Sobre el Proyecto

Este repositorio contiene el código fuente de mi sitio web de portfolio profesional. El proyecto ha sido diseñado y desarrollado desde cero con un enfoque híbrido, demostrando la sinergia perfecta entre el desarrollo técnico frontend y la dirección de arte multimedia. 

No es solo un contenedor de trabajos, sino una pieza de ingeniería y diseño en sí misma optimizada para ofrecer una experiencia interactiva fluida, responsiva y de alto rendimiento.

## 🛠️ Tecnologías y Herramientas

### Desarrollo Frontend
*   **HTML5:** Estructura semántica, accesible y optimizada para SEO.
*   **CSS3:** Estilos personalizados, diseño responsivo y transiciones fluidas.

### Diseño & Multimedia
*   **Figma:** UI/UX Design y prototipado interactivo.
*   **Adobe After Effects / Premiere Pro:** Creación de motion graphics, reels y animaciones de alta fidelidad.

## 📦 Arquitectura y Optimización

Para garantizar que el sitio web cargue de forma instantánea sin importar el peso de los recursos multimedia, se implementó la siguiente estrategia:

1.  **Despliegue Continuo (CI/CD):** Alojado de forma global en **Vercel**, aprovechando su red de distribución de contenido (CDN) para lograr tiempos de respuesta mínimos. Cada cambio en esta rama principal se actualiza automáticamente en producción.
2.  **Entrega Multimedia Externa:** Para no penalizar la velocidad de la web, todos los recursos de video y animaciones pesadas se sirven de manera externa a través de servidores optimizados de streaming y entrega multimedia, evitando saturar el ancho de banda del cliente.

## 📂 Estructura del Proyecto

El repositorio está organizado de la siguiente manera:

*   `index.html` - Página de inicio y presentación principal.
*   `web-portfolio.html` - Galería y casos de estudio de proyectos de desarrollo web.
*   `design-portfolio.html` - Galería de proyectos de diseño gráfico y multimedia.
*   `portfolio-details.html` - Plantilla para la vista detallada de cada proyecto.
*   `style.css` - Hoja de estilos global y diseño responsivo.
*   `assets/` - Directorio para imágenes locales estáticas e iconos optimizados.
